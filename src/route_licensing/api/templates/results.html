📋 How was this route assessed? Methodology and thresholds applied
{% set t = result.applied_thresholds %} {# ── Step-by-step formula ─────────────────────────────────────── #}
📐 How the assessment works

The analysis is driven by a single question: can passengers already make these journeys using the existing network? The assessment works through three tiers in order, stopping as soon as coverage is established.

{# ── Signal A: OD Journey Check ────────────────────────── #}
Journey check (primary question)

Can passengers already make these journeys using the existing network? This is the headline question, assessed in three tiers:

Tier 1 Direct existing service — an existing bus already makes the same journey at the same time of day.
≥ {% if t %}{{ (t.get('od_reject_ratio', 0.80) * 100) | int }}{% else %}80{% endif %}% of journeys covered → 🔴 High overlap  ·  ≥ {% if t %}{{ (t.get('od_changes_ratio', 0.60) * 100) | int }}{% else %}60{% endif %}% → 🟡 Moderate overlap
Exception: if existing services are already at capacity (high demand and infrequent), High overlap is softened to Moderate — the new route fills a genuine capacity gap.
Tier 2 Two-leg interchange journey — no direct service, but the passenger could board an existing bus, transfer at an intermediate stop and reach their destination on a second existing service within a 5 to 45 minute connection window.
≥ {% if t %}{{ (t.get('od_changes_ratio', 0.60) * 100) | int }}{% else %}60{% endif %}% of journeys possible this way → 🟡 Moderate overlap (journey is possible but requires an interchange)
Tier 3 Walk access to a nearby stop — no direct or interchange service, but the passenger could walk ≤ {% if t %}{{ (t.get('od_walk_radius_metres', 400)) | int }}{% else %}400{% endif %} m to a nearby stop and catch an existing bus to their destination.
≥ {% if t %}{{ (t.get('od_changes_ratio', 0.60) * 100) | int }}{% else %}60{% endif %}% covered this way → 🟡 Moderate overlap (softer signal — journey is possible but inconvenient)
Load Is existing supply meeting demand?
High demand and infrequent existing service → unmet demand — softens High overlap to Moderate.
Low demand on overlapping corridors → commercial viability risk — Low overlap becomes Moderate.
{# ── Assessment signal priority ─────────────────────────── #}
Assessment signal
The OD journey check is the primary signal. A busy stop does not indicate route duplication; only an already served journey does.
Fallback: if all stop IDs are unresolved and OD data is unavailable, stop and trip scoring is used and flagged in the analysis summary.
{# ── Service bands ────────────────────────────────────────────── #}
Service period bands used for all comparisons: AM Peak (before 09:30) · Midday (09:30 to 16:00) · PM Peak (16:00 to 19:00) · Evening (after 19:00). A proposed stop is only compared against existing services in the same band, so a morning departure is never flagged against an evening service.

🔁 A→B Journey Coverage Analysis

PRIMARY SIGNAL

For each proposed journey (origin → destination stop pair), the analysis checks whether passengers can already make the same trip on existing services. This is the primary assessment signal — a shared stop does not make a route duplicative; only a shared journey does.

{# ── What this section does ──────────────────────────────────────────── #}
How this analysis works For every journey on the proposed route, the system works through three questions in order:
Tier 1: Direct service
Can the passenger board at stop A and reach stop B on an existing bus, in the same direction, at roughly the same time of day?
Strong signal against the new route.
Tier 2: Two-leg interchange journey
No direct service, but could the passenger take an existing bus to an intermediate stop and connect to a second existing service to reach their destination?
Moderate signal — journey is possible but requires an interchange.
Tier 3: Walk access
No direct or interchange service, but could the passenger walk ≤{{ (t.od_walk_radius_metres if t else 400) | int }} m to a nearby stop and catch an existing bus to a stop near their destination?
Softer signal — journey is possible but inconvenient.
Load check: is demand being met?
Even if covered by Tier 1, are existing services already running at capacity? High demand and infrequent service means the new route fills a real gap.
Can soften the High overlap signal if existing supply is insufficient.
{# ── Load signal banner ──────────────────────────────────────────────── #} {% if od_load != 'unknown' %}
{% if od_load == 'unmet_demand' %} 📈 Unmet demand signal: existing services are infrequent but passenger demand is high. The new route would fill a genuine gap in supply. {% elif od_load == 'overloaded' %} ⚠ Capacity pressure: existing services are frequent but demand is also high. Buses may be at or near capacity and a new route could relieve overcrowding. {% elif od_load == 'low_demand' %} 📉 Low demand signal: existing services on overlapping corridors carry low passenger volumes. A new route risks further thinning ridership without commercial justification. {% else %} 📊 Adequate supply: no strong evidence of either overcrowding or unmet demand on existing services. {% endif %}
